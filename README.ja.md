# Codex Kanban

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

人が承認してから実行し、レビューで仕上げる Codex CLI 用のローカル・タスクボードです。タスクごとにあなたが承認し、エージェントが自分のコンピュータ上で実行し、レビューで承認して初めて完了になります。個人プロジェクトであり、OpenAI の公式製品ではありません。

**1人用のプレビュー版で、macOS を優先しています。** Python 標準ライブラリ、SQLite、素の JavaScript のみで、pip/npm の依存関係やビルドは不要です。Windows での実行は未対応、Linux は十分に検証していません。スマートフォンからはブラウザで操作できますが、タスクは常にホストのコンピュータで実行されます。

画面は English・简体中文・日本語 に対応しています（PC はサイドバー、スマートフォンは「プロジェクト設定」で切り替え）。選択はブラウザに保存されます。プロジェクト名、タスク、コメント、エージェントの出力など、あなたが書いた内容は翻訳されません。

## はじめに

1. **Code → Download ZIP** でダウンロードして展開するか、`git clone https://github.com/xij669/codex-kanban.git` を実行します。
2. そのフォルダで Python 3.9 以上を確認して起動します。
   ```sh
   python3 --version
   python3 -B server.py
   ```
3. [http://127.0.0.1:8765](http://127.0.0.1:8765) を開きます。初回はデモ用プロジェクトが作られます。`Ctrl+C` で停止します。
4. ポートが使用中の場合は `BOARD_PORT=8766 python3 -B server.py` で起動し、そのポートを開きます。

ボードを試すだけなら Codex は不要です。タスクを実行するには [Codex CLI](https://developers.openai.com/codex/cli/) をインストールしてログインし、同じターミナルで `codex --version` と `codex exec --help` が動くことを確認してください。CLI は `--json`、`--approve-for-me`、`--cd`、`--skip-git-repo-check` に対応している必要があります。モデル一覧はローカルの Codex キャッシュから読み込み、ない場合は CLI の既定モデルを使います。

## 使い方

| 列 | 担当 | 内容 |
| --- | --- | --- |
| バックログ | あなた | アイデアや下書き。自動では実行されません。受け入れ基準を書くと次へ進められます。 |
| 未着手 | エージェント | 表示順に実行：緊急 → 高 → 中 → 低、同じ優先度は古い順。 |
| 進行中 | エージェント | 経過時間と現在の作業を表示。いつでも停止できます。 |
| レビュー中 | あなた | **承認**するか、修正内容を書いて**修正を依頼**し未着手へ戻します。失敗・停止・タイムアウトも理由付きでここに戻ります。 |
| 完了 / キャンセル済み | — | 既定では非表示。 |

同時に実行するタスクは1つで、緊急タスクも実行中のタスクを中断しません。1回の実行は既定で60分で停止します（`BOARD_RUN_TIMEOUT_MINUTES`、`0` で無制限）。**自動実行**はプロジェクトごとの設定で、既定はオフです。

## データを保ったまま更新する

プロジェクト、タスク、コメント、実行履歴、プロジェクト設定は、ボードを起動したフォルダの `board.sqlite3` に保存されます。言語と選択中のプロジェクトはブラウザに保存されます。**更新でこれらが置き換えられることはありません。**

更新の前に、実行中のタスクの終了を待つか停止し、ボードのサーバーを止めてください。更新後も同じアドレスとポートで開けば、言語と選択中のプロジェクトはそのまま残ります。

- **Git でインストールした場合：** 既存のフォルダで `git pull --ff-only` を実行します。`board.sqlite3`、`backups/`、`.remote/` は Git の対象外なので上書きされません。プログラムを自分で変更している場合は通常どおり競合を解決し、強制リセットでデータを消さないでください。
- **ZIP でインストールした場合：** 新しい版を**別のフォルダ**に展開し、そのフォルダで次を実行します。

  ```sh
  python3 -B update.py "/既存の/codex-kanban/へのフルパス"
  ```

  置き換えるのは `VERSION` と6つのプログラムファイルだけです。先に既存フォルダの `backups/` に SQLite のバックアップを作り、実行中のタスクがあれば更新を中止します。データベース、プロジェクト、`.remote/`、その他のファイルは変更しません。その後は**既存のフォルダから**起動してください。新しい ZIP を古いフォルダに上書きしないでください。

データベースの移行は起動時に自動で行われ、構造を追加するだけです。最初のプレビュー版のデータベースでテストしています（`compat_test.py`）。元に戻す場合はサーバーを止めて `backups/` から復元してください。バックアップ以降の変更は失われます。

## データとセキュリティ

- `127.0.0.1` のみで待ち受け、**ログイン機能はありません**。インターネット、GitHub Pages、公開プロキシに公開したり、Tailscale Funnel を有効にしたりしないでください。スマートフォンからの利用は [REMOTE.md](REMOTE.md)（英語）を参照してください。
- ボードはプロジェクトフォルダを読み書きするエージェントを起動します。まずはテスト用フォルダかバージョン管理下で使ってください。サンドボックスはバックアップの代わりにはなりません。
- Codex はタスクの内容と読み込んだファイルを設定済みのモデルサービスに送ります。送ってはいけない情報を含めないでください。認証情報は CLI が管理します。
- 再起動すると実行中のタスクには再接続できません。終了前にタスクを停止してください。
- 未対応：利用上限回復後の自動再開、複数ユーザー、自動バックアップ、Claude 実行環境。

詳細：[SECURITY.md](SECURITY.md)（英語）。

## AI エージェントにインストールを任せる

リポジトリのリンクか展開したフォルダを、次の依頼文と一緒にエージェントへ渡してください。

> このリポジトリの AGENTS.md、README.md、SECURITY.md を先に読み、AGENTS.md の「Import / run」を順番に実行してください。フォルダに `board.sqlite3` がすでにある場合は更新として扱い、私のデータをすべて残してください。ボードをバックグラウンドで起動し、`/api/state` のバージョンが `VERSION` ファイルと一致することを確認してから、アクセス用のリンクと停止コマンドを教えてください。ボードの起動だけを行い、実際のタスク作成、自動実行の有効化、既存プロジェクトのファイル変更、認証情報の読み取りやアップロードはしないでください。タスクの実行を頼んだ場合は、先に Codex CLI を確認し、テスト用フォルダを私に確認してください。サービスをネットワークに公開したり、Tailscale やログイン項目を変更したりしないでください。

エージェント向けガイド：[AGENTS.md](AGENTS.md)（英語）。個人の Codex 設定、データベース、API キー、Tailscale のファイルは不要です。

## 開発

```sh
fail=0; for t in *_test.py; do python3 -B "$t" >/dev/null 2>&1 || { echo "FAILED: $t"; fail=1; }; done; [ "$fail" = 0 ] && echo "ALL TESTS PASSED"
```

テストは一時データベースと模擬実行環境を使い、実際のモデルは呼び出しません。画面の文言は `i18n.js` でキーごとに管理し、`i18n_test.py` が3言語すべてそろっているか確認します。ショートカット：`N` 新規タスク、`/` 検索、`Esc` 閉じる。詳しくは [CONTRIBUTING.md](CONTRIBUTING.md)（英語）。
